## 1. Visual Alignment With Our Task 1 Brand & Design System Tokens
Instead of sending an unstyled plain-text string (`"Your code is 849204"`), which looks indistinguishable from a generic phishing message, we engineered an HTML email table layout (`buildBrandedVerificationEmailHtml` in `src/lib/verification.ts`) using inline CSS mapped directly to our **Task 1 Tekrise Academy brand tokens**:
* **Primary Brand Header (`#006D35` Deep Emerald) & Accent Rule (`#00E676` Vibrant Green):** Matches the exact surface and primary brand tokens of our `/auth` portal card so the student immediately recognizes visual continuity between the web tab they just submitted and the email that lands in their inbox.
* **Monospace OTP Display (`JetBrains Mono`, `36px`, `letter-spacing: 0.22em`):** Renders the 6-digit code (`849204`) inside a high-contrast `#F0FDF4` container with a `2px dashed #006D35` border so the student can read or copy the 6 digits at a glance on a small mobile screen without squinting or confusing `0` and `O`.
* **Email-Client Compatibility:** Uses table-based layout (`<table role="presentation">`) and inline styles because Gmail and Outlook strip external `<style>` sheets and modern CSS Grid/Flexbox properties.

## 2. Copy Decisions: Contextual Trust Signals & Anti-Phishing Phrasing
Every sentence in the email copy serves a specific security or usability purpose:
1. **Personalised Context Binding (`fullName`, `track`, and `matricPin`):** Greeting the student by their full legal name (*"Hello **Oluwaseun Adeleke**"*), naming their exact chosen Cohort 04 track (*"**Full-Stack Software Engineering**"*), and referencing their **Bursary Receipt PIN (`#48291`)** proves to the recipient that this email originated from their authentic Tekrise Academy registration session rather than a mass-spoofed phishing blast.
2. **Subject Line Prefixing (`[849204] Verify your Tekrise Academy...`):** Placing the 6-digit code at the very start of the email `Subject` line allows students on iOS and Android to read the 6-digit code directly from their mobile lock-screen push notification banner without even waiting for the mail app to load over slow mobile data.
3. **Explicit Expiry & Single-Use Warning (*"Valid for 8 minutes • Single-use only"*):** Sets clear expectations so the student completes verification immediately rather than leaving the tab open for an hour.
4. **Anti-Social-Engineering Warning:** Explicitly states that *"Tekrise Academy bursary and academic staff will never ask you for this code over WhatsApp, phone, or SMS"*, protecting students against imposters attempting account takeover.
